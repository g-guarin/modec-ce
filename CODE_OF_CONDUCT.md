# Código de conducta / Code of conduct

Este proyecto es técnico y se discute con evidencia. Para que sea un lugar donde se pueda trabajar:

- Trate a las demás personas con respeto. Critique el código, los datos y los argumentos, no a quien los escribe.
- No se admiten el acoso, los insultos, la discriminación ni publicar datos personales de terceros.
- Quien afirme una cifra cita su procedencia; quien la discuta, también.
- Se escribe en español o en inglés.

La persona que mantiene el proyecto puede editar o eliminar comentarios, cerrar incidencias y bloquear cuentas que incumplan estas normas.

**Cómo informar de un problema de conducta:** mientras el proyecto no tenga un correo propio, use el reporte privado de GitHub (*Security → Report a vulnerability*) e indique que es un asunto de conducta.

*English:* be respectful, argue with evidence, no harassment or discrimination, and never publish other people's personal data. Report conduct issues through GitHub's private report (*Security → Report a vulnerability*) until the project has its own email address.
